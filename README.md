# GIS kiosco (GitHub Pages)

Kiosco, mapa y oficina leen/escriben **Google Sheets** vía Apps Script.

- Kiosco: `index.html` (PIN + QR, sin código manual)
- Mapa: `mapa.html`
- Oficina / QR: `oficina.html`

Config: `config.js` (`GIS_WEBAPP_URL` + `GIS_SHEET_URL`).

Pasos de despliegue del Script: ver `PASOS-ONLINE.md` en el repo `sistema gis oficial` o las instrucciones del README.
